busabunga.com

Type

Website build + SEO

Date

Launched June 2026

Role

Design, build, SEO

Client

PT Tjikko Sentral Industrial

A commercial site for Tjikko's decorative foam (busa bunga) line, built end to end in React with Claude Code as the development partner. Design, build, content and search strategy were all mine. There was no existing site, no legacy traffic, and no ad budget to lean on.

What I built

  • Keyword and intent research before any code was written
  • Information architecture built around buyer intent, not the product catalogue
  • Full React build, AI-assisted with Claude Code
  • Technical SEO foundation: crawlability, schema, Core Web Vitals
  • Long-tail landing pages for florists, wholesale buyers and private-label enquiries
  • Search Console and analytics set up from day one

The challenge

A brand-new domain competing for commercial keywords that established suppliers and marketplaces already owned. No backlink profile, no history, and no paid support. The only route to visibility was getting the technical foundation and the search intent right the first time.

How I approached it

I mapped the commercial keyword set before writing a line of code, then shaped the site structure around how buyers actually search rather than how the company organises its products. Primary terms were floral foam, wet and dry floral foam, busa bunga and floral foam indonesia; secondary terms covered supplier, distributor, grosir and private-label variations. Each target term got a single page that clearly owned it, so no two pages competed with each other.

Result

Within roughly one month of launch the site held #1 and page-one Google positions for its target commercial keywords — a result that came from structure and intent matching rather than from authority it had not had time to build.

Stack

  • React
  • Claude Code
  • Technical SEO
  • Search Console
  • GA4

Sekolah Trinitas

Type

Local SEO

Date

2026

Role

SEO & website developer

Client

Sekolah Trinitas — via RIAS Strategic

Local search work for a Christian trilingual school in Bandar Lampung, delivered through the RIAS Strategic freelance talent pool. The brief was simple to state and hard to win: own the terms parents actually type when they are choosing a school.

What I built

  • Keyword mapping across the five priority local terms
  • On-page rewrite so each term had one page earning it
  • Technical fixes and crawl clean-up
  • Local relevance signals tightened
  • Rank tracking against the target set

The challenge

Education keywords in a regional market are crowded with directories, aggregators and long-established institutions. Ranking meant beating pages with far more authority, on terms where realistically only the top result converts — parents do not scroll for a school.

How I approached it

I rebuilt the on-page and technical foundation around the five keywords that mattered and made sure each one had a clear, single page earning it, which removed the cannibalisation that was splitting the site's own relevance. Local signals were tightened so the school read unambiguously as a Bandar Lampung institution.

Result

#1 Google rankings for all five target keywords: sekolah kristen lampung, sekolah kristen terbaik lampung, sekolah trilingual terbaik lampung, sekolah trilingual lampung, and sekolah kristen lampung paling bagus.

Hermes AI Agent System

Type

AI automation

Date

2026 — ongoing

Role

Architect & builder

Client

Self-hosted / internal

A self-hosted multi-agent system running real daily work — not a demo and not a prototype. Claude API handles the reasoning, n8n orchestrates the workflows, and MCP connects the whole thing to live WordPress sites and analytics properties.

What I built

  • Multi-agent framework running on a self-hosted VPS
  • Claude API as the reasoning engine
  • n8n for scheduling and workflow orchestration
  • Claude Desktop + MCP connected to live WordPress sites
  • Claude Code and Git development workflow
  • RAG architecture for document grounding
  • Full multi-page client website builds executed through MCP
  • SEO, GEO and AEO documentation systems
  • GA4 audits and a daily reporting agent

The challenge

Most AI automation stops at the proof-of-concept stage — impressive in a screenshot, unreliable the moment it has to run unattended against production systems. The hard part is not the model call; it is everything around it: scheduling, error handling, credentials, and knowing when the output is wrong.

How I approached it

I built Hermes as infrastructure rather than as a script. Agents are composable skills with a Git workflow behind them, MCP handles the integrations into live systems, and n8n owns scheduling and retries. A separate system, built on Claude scheduled tasks with MCP into Google Drive and Gmail, validates customer quotations against purchase orders on line items, pricing and expiry, and reports hourly.

Result

A GA4 Daily Reporter runs in production across three properties. The quotation validation layer has been live since July 2026. It is deliberately too early to claim a catch rate or a time saving — those numbers will exist once the system has a real track record behind it.

Stack

  • Claude API
  • Claude Code
  • MCP
  • n8n
  • Docker
  • Self-hosted VPS
  • RAG
